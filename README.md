# pisces312

**Android engineer — on-device media, inference and system tools.**
Everything runs locally: no account, no upload, no telemetry.

### Selected work

- **[StreamClip](https://github.com/pisces312/StreamClip)** ★34 — Lossless, near-instant video editing on Android. Stream-copy trim / merge / audio extract with no re-encoding, hardware-accelerated H.264/H.265 compression, full metadata preserved. Kotlin + FFmpeg. [Download APK →](https://github.com/pisces312/StreamClip/releases)
- **[droid-llm](https://github.com/pisces312/droid-llm)** — Multi-engine on-device LLM chat and benchmark: LiteRT-LM, MNN, Genie, llama.cpp.
- **[wavefall](https://github.com/pisces312/wavefall)** — 4K 下落式音游，傅里叶谱面生成，全自有代码，不依赖第三方播放器。
- **[SafePersonalDataExport](https://github.com/pisces312/SafePersonalDataExport)** — Export SMS, call logs and contacts to JSON/CSV, entirely on-device.

Maintained fork: **[PixelPlayerOSS](https://github.com/pisces312/PixelPlayerOSS)** — offline music player (Compose + Media3), available on F-Droid.
